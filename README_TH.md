# Issue Scanner Mobile (พร้อมไฟล์เสียง, ปุ่มกดสแกนกล้อง และหน้าต่างยืนยันผล OK)

## สิ่งที่เพิ่มเข้ามาในเวอร์ชันนี้
1. **หน้าต่างแจ้งผลการสแกนพร้อมปุ่ม `OK` (`#scanResultModal`):**
   - **เมื่อสแกนผ่าน (สีเขียว ✅):** แสดงหน้าต่างสรุป `Part No.`, `จำนวน (Qty)` และช่องทางที่สแกน พร้อมปุ่ม **`OK`**
   - **เมื่อสแกนไม่ผ่าน (สีแดง ❌):** แสดงสาเหตุที่ไม่ผ่าน (เช่น รูปแบบช่องไม่ครบ 8 ช่อง, ข้อมูลไม่ครบ, Barcode ซ้ำ หรือไม่พบ Barcode ในกรอบกล้อง) พร้อมปุ่ม **`OK`**
   - รองรับทั้งการแตะปุ่ม `OK` บนหน้าจอ หรือกดปุ่ม `Enter` / `Esc` บนคีย์บอร์ดหรือเครื่องสแกน
2. **โฟลเดอร์ไฟล์เสียง (`sounds/`):**
   - `sounds/click.wav` : เสียงคลิกเมื่อกดปุ่มต่าง ๆ
   - `sounds/beep-success.wav` : เสียงปี๊บ 2 จังหวะเมื่อสแกนผ่าน (+ สั่นบนมือถือ)
   - `sounds/beep-error.wav` : เสียงเตือนทุ้มเมื่อสแกนไม่ผ่าน (+ สั่นเตือน)
   - รองรับการทำงาน Offline ผ่าน `sw.js` และมีระบบเสียงสำรองผ่าน Web Audio API พร้อมปุ่ม **เปิด/ปิดเสียง** ที่มุมขวาบน
3. **ปุ่มกดสแกนสำหรับกล้องมือถือ (`🎯 กดเพื่อสแกน`):**
   - เล็ง Barcode ในกรอบแล้วกดปุ่ม `🎯 กดเพื่อสแกน` เพื่ออ่านทีละรายการ หรือเลือกติ๊ก **สแกนอัตโนมัติต่อเนื่อง** ได้

## รักษากติกาจากโค้ดต้นฉบับ
- localStorage key ยังคงเป็น `scans` เพื่ออ่านข้อมูลเดิมได้
- แยกข้อมูลด้วย `;` และต้องมีอย่างน้อย 8 ช่อง (Part No. = ช่องที่ 1, Qty = ช่องที่ 5)
- ป้องกันการบันทึก Barcode เดิมซ้ำ
